## 📱 APP 前端核心功能

### 1. 首页推荐、附近板块，同城社交核心

内置**推荐、附近、活动**三大标签页。

- 附近推荐：自动定位，展示附近用户、附近帖子，支持性别、年龄段筛选，快速找到同城用户；
- 附近帖子：用户发布图文动态、相亲交友帖、结伴邀约内容，带图片展示，支持点赞评论；
- 推荐流：智能推送优质用户、热门动态，打造信息流种草体验；
- 活动板块：可发布线下聚会、相亲活动、兴趣结伴活动，吸引用户线下互动。

### 2. 多类型内容发布，图文视频社交

支持发布图文、短视频、音乐、约伴帖子，用户自由分享生活、相亲自我介绍、结伴出行需求。搜索功能强大，可以分别检索用户、图文、视频、音乐、约伴内容，快速找人、找话题。

### 3. 即时通讯私聊 IM

内置即时聊天模块，双向私信沟通，支持文字消息，是婚恋交友场景核心功能，用户相互匹配后可以直接在线沟通。

### 4. 个人中心（OWN 我的）

个人主页展示昵称、粉丝、关注、访客数据；分类管理**原创、收藏、评论、草稿**。
支持个人信息设置：头像、性别、年龄、地区、手机号、用户等级等资料编辑；附带清除缓存、意见反馈、关于我们、系统设置等工具入口。

### 5. 弹窗交互组件

配套全套 UI 弹框：关注成功、发送成功、升级提示、取消关注等交互弹窗，整套 UI 风格统一，黄黑潮流年轻风格，视觉辨识度高。
